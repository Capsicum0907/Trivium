# Trivium

[English](README.md) | 日本語

つるはし・斧・シャベルを1本にまとめたパクセルを追加します。3つが掘れるブロックをすべて掘り、
右クリックの動作も3つぶんこなします。クワの範囲も掘れて、耕すこともできます。

- 素材は木・石・鉄・金・ダイヤモンド・ネザライトの6種類です。掘る速さは同じ素材の道具と同じです。
- 右クリックでは、原木の皮剥ぎ・銅の酸化落とし・脱ロウ・耕地作り・焚き火の消火ができます。
- 道は作れません。耕地作りと同じ操作になるため、耕地作りを残しています。
- 同じ素材のつるはし・斧・シャベル3本で作ります。3本とも耐久が減っていないものが必要です。
- 耐久は3本ぶんです。
- 木のパクセルはかまどの燃料になります。
- エンチャントはつるはし・斧・シャベルに付くものが付きます。
- 他の Mod のブロックも、バニラと同じ分類に入っていれば掘れます。

## 対象

| | |
|---|---|
| Minecraft | 1.21.1 |
| ローダー | NeoForge 21.1.248 |
| Java | 21 |

## ビルド

```
run.bat                   # コンパイルして開発クライアントを起動
gradlew build             # jar を作る
gradlew runGameTestServer # ゲームテストを実行
gradlew runData           # モデル・レシピ・言語ファイル・タグを作り直す
```

`JAVA_HOME` が JDK 21 を指しているか `java` が `PATH` にある必要があります。
